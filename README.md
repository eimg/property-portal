# Property Portal

Property Portal is a marketplace for discovering properties for sale or rent in Yangon and Mandalay. This coordination directory contains the product specification and links to the independent projects that make up the current web experience.

## Projects

- [`app/`](app/README.md) — browser application for property discovery and account workflows.
- [`api/`](api/README.md) — service that provides listings, accounts, inquiries, and administration operations.
- A mobile client is in the product scope but is not included in this checkout.

Each project has its own Git repository and can be run independently. To try the complete local experience, start the API first, then the web app. See each project's README for setup and demo account details.
